# 이동 중 독서/활동 기록 — Working prototype (Claude 버전)

연구용 PoC입니다. 위치·환승·탑승·도착 감지와 밀리의 서재 앱 실행은 **없고 모두 시뮬레이션**입니다. 데이터는 해당 브라우저의 localStorage에만 저장되며 외부로 전송되지 않습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다(빌드 불필요). 서버가 필요하면 이 폴더에서 아래 명령을 실행합니다.

```bash
python3 -m http.server 8765
# http://localhost:8765/index.html
```

| 주소 옵션 | 설명 |
|---|---|
| `?reset=1` | 저장된 데이터를 지우고 처음부터 시작 |
| `?speed=4` | 환승·도착 시간을 4배 빠르게 재생 |
| `?screen=home` | 지정한 화면으로 바로 열기 (`&profile=fresh`로 신규 사용자 상태) |
| `?bare=1` | 시뮬레이터 패널 없이 프레임만 표시 |

## 시나리오

전자책 읽기 → 데미안 → 밀리의 서재 → 독서 → 환승 직전 저장 → 이동으로 독서 중단 → 복귀 안내 → 밀리의 서재로 돌아가기 → 데미안 이어 읽기 → 목적지 도착 → 이동 및 활동 마무리

- 기존 사용자: 로그인하면 이전 활동(데미안)이 복원된 홈으로 들어갑니다. 대표 시나리오입니다.
- 신규 사용자: 회원가입 → 온보딩 → 이전 기록이 없는 첫 사용 홈으로 들어갑니다. 로그인 화면은 신규 사용자가 아닙니다.

## 독서 중 Dynamic Island

- 독서 화면에서는 처음부터 compact(`● 활동 중`)로 보입니다. 화면은 그대로 두고 Island만 `활동 중 → 환승 3분 → 2분 → 1분 → 곧 환승해요`로 바뀝니다.
- 3/2/1분 상태에서 Island를 누르면 펼쳐집니다(`전자책 읽기 / 데미안 · 이번 활동 N분째 / 환승까지 N분`, 오른쪽 Stop 버튼). 바깥을 누르면 접히고 활동은 계속됩니다.
- Stop은 현재 전자책 활동만 멈추고 환승 기록/대기 화면으로 이동합니다. 이동 상태는 유지됩니다.
- Stop 없이 안내를 무시해도 탑승이 자동으로 감지되어 이동이 이어집니다. 복귀하면 새 활동이 아니라 기존 활동이 이어지고, 목적지 접근도 같은 방식으로 도착 흐름으로 넘어갑니다.
- 데스크톱에서는 프레임 옆 시뮬레이터 패널(환승 직전, 탑승 감지, 목적지 도착, 이동 시간 +10분)로 상황을 대신 발생시킬 수 있습니다.
